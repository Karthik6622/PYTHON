Optional PDF fonts
==================
Drop TrueType files here to override the system fonts used for the PDF and cover text.

Latin:        NotoSerif-Regular.ttf, NotoSerif-Bold.ttf, NotoSerif-Italic.ttf, NotoSerif-BoldItalic.ttf
Tamil:        NotoSansTamil-Regular.ttf, NotoSansTamil-Bold.ttf
Hindi:        NotoSansDevanagari-Regular.ttf, NotoSansDevanagari-Bold.ttf
Japanese:     NotoSansJP-Regular.ttf, NotoSansJP-Bold.ttf

Noto fonts are free (SIL Open Font License): https://fonts.google.com/noto
