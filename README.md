## assistant app - automated tests

Generated by **RK Testing Studio** (Playwright + TypeScript).

* Application under test: `https://personalpartner.streamlit.app/` (override with the `BASE_URL` environment variable)
* Browser: `chromium` (override with the `BROWSER` environment variable)
* Element lookups live in `config/locators.json`. Tests never contain raw selectors.
* Secrets are never stored here. Values written as `{{env:NAME}}` are read from environment variables at run time.

### Setup

```
npm install
npx playwright install
```

### Run

```
BROWSER=chromium npx playwright test
```

Results: `reports/junit.xml`. Evidence per test case (steps, DOM snapshot, screenshot) is written to `reports/evidence/<TEST_CASE_ID>/`.
