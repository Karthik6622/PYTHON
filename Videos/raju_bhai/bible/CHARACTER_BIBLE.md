# Raju Bhai - Character Bible (locked design)

Use these exact traits in every scene and every generation prompt. Never change them between episodes.

| Item | Locked value |
|------|--------------|
| Species / build | Large anthropomorphic Bengal tiger, powerful athletic build |
| Fur | Orange body, strong black stripes, white fur on cheeks, chin and chest |
| Eyes | Amber / golden, slit pupils |
| Mark | Small scar (two short lines) above the **right** eyebrow (left side as we face him) |
| Jacket | Dark forest-green fitted jacket |
| Shirt | Black T-shirt (V neck, white chest fur visible) |
| Trousers / boots | Dark trousers, heavy boots |
| Pendant | Silver chain with a silver **RB** plate |
| Vehicle | Black vintage motorcycle |
| Face | Confident, friendly |
| City | Metro Nagar - Indian city, neon signs, wet roads, orange (key) / blue (rim) lighting |
| Grade | Orange light from the left, blue rim light from the right |

Colour values used by the sample renderer: orange `#E8731A`, jacket `#1F3D2B`, amber `#FFB000`, silver `#C8CDD4`.

## Recurring cast
- **Chintu** - Raju's loyal sidekick (introduce in Part 2). Suggested: a small street-smart mongoose.
- **Kaal Naag** - the master villain behind the robotic cobras (revealed in Part 8).
- **The duplicate Raju** - robotic imitation (Parts 2-3).
- **Black eagle** - Season 2 hook (Part 10).
